## CN2 GIA、CN2 GT、163：名字都叫 CN2，实际差三档

搜"日本cn2 vps"的人常被这三个缩写绕晕，它们的差别决定了你晚上八点打开网站是秒开还是转圈。

**163 骨干网（AS4134）** 是默认线路，便宜、容量大，晚高峰丢包率能冲到 30% 以上。你买到的便宜日本 VPS 如果没特别标注线路，大概率走这条。

**CN2 GT（AS4809 Global Transit）** 本来是奔着解决拥堵去的，国际段走 CN2，国内段可能切回 163。2019 年之后它的实际表现已经回落到接近 ChinaNet 的水平，价格比 GIA 低，但别指望它解决晚高峰。

**CN2 GIA（AS4809 Global Internet Access）** 全程走电信高速通道，丢包低、延迟稳，也是价格最贵的一档。贵的原因是成本确实高：搬瓦工公开报价里，CN2 GIA 原生 IP transit 高达 $120/Mbps。这就是为什么标着 CN2 GIA 的低价套餐，回国带宽普遍只有 2–10Mbps。

还有一个新选项 **AS23764 CTGNet**，是电信较新的产品，实际表现和定价与 CN2 GIA 接近，遇到时可以当作同一档看待。

需要说清的一点：CN2 GIA 解决的是丢包和高峰期拥堵，改不了物理距离。东京到北京往返仍然是 80ms 左右，想要 30ms 以内只能选中国大陆或香港节点。

## 常见问题

**日本 CN2 VPS 需要备案吗？** 不需要。海外服务器不受国内 ICP 备案管辖，开通即用。

**2M 带宽够用吗？** 纯文字站、日均 1000 IP 以内够。图片多的电商站、视频、下载站不够，5M 起步，10M 更稳。

**一定要买原生 IP 吗？** 建站、跨境访问、开发测试用默认 IP 就行。要解锁日本本地流媒体、注册日本本地服务、做日本 SEO，才需要单独申请。

**晚高峰怎么测？** 机器到手先跑 mtr 看回程路由是否全程走 CN2，再在国内不同运营商网络下 ping，重点测晚上 8 点到 11 点。测评里的延迟数字只能当参考，你自己的线路环境才算数。

**东京和大阪怎么选？** 东京到国内主要城市 50–80ms，回程线路资源更全。大阪走 Softbank 路径，部分联通用户体验更好。没有特殊偏好的话，东京的线路选择更多。
